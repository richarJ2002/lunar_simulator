# Martian plain stub

> Code is truth — this environment is a placeholder, not a full world.

Placeholder Martian variant so the `environment/martian/` tree exists. A
minimal valid SDF with an empty ground plane only — no terrain meshes and
no `.blend` authoring sources.

Where: `environment/martian/plain_stub/plain_stub.sdf`
([GitHub](https://github.com/richarJ2002/space_robotics_simulator/blob/main/environment/martian/plain_stub/plain_stub.sdf)).

No supported launch path runs on this stub; Alpha is supported on
[Lunar crater field](crater-field.md). See [Environments](index.md) for
the launcher matrix.
